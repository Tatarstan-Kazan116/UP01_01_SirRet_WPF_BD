## Описание

Приложение разработано в рамках учебной практики по специальности **09.02.07 «Информационные системы и программирование»**. Оно предназначено для автоматизации работы автосервиса и включает:

- Авторизацию и регистрацию пользователей с разграничением ролей (User / Admin)
- Управление справочными данными (клиенты, автомобили, сотрудники, категории услуг)
- Ведение заказ-нарядов (платежей)
- Построение интерактивных диаграмм по платежам пользователей
- Экспорт отчётов в Microsoft Word (.docx) и Excel (.xlsx)
- Поддержку светлой и тёмной тем оформления (DynamicResource)
- Защиту от подбора пароля (капча после 3 неудачных попыток)

## Технологии

- **Язык программирования:** C# 8.0+
- **Платформа:** .NET Framework 4.7.2 / WPF
- **IDE:** Microsoft Visual Studio 2022
- **База данных:** Microsoft SQL Server (Entity Framework, Database First)
- **ORM:** Entity Framework 6
- **Диаграммы:** System.Windows.Forms.DataVisualization.Charting
- **Экспорт:** Microsoft.Office.Interop.Word, Microsoft.Office.Interop.Excel
- **Безопасность:** Хеширование паролей алгоритмом SHA-1

---

## Требования

- Windows 10/11
- .NET Framework 4.7.2 или выше
- Microsoft SQL Server 2016+ (LocalDB или Express)
- Microsoft Office 2016+ (для корректной работы экспорта в Word/Excel)
